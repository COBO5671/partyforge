# PartyForge

PartyForge is a small, self-hosted event invitation and RSVP app. Guests do not need accounts. Each event can have a completely different AI-designed visual theme while the RSVP fields and event data stay reliable.

## Included in this MVP

- Private organizer login
- Create and edit events
- Optional banner image
- Unique named guest links
- Open RSVP link when enabled
- Yes / maybe / no responses, party size, dietary notes, and comments
- Guest CSV export
- Poll / superlative blocks
- Potluck sign-up blocks
- Free-text potluck contributions saved to each guest’s personal link
- Schedule and information blocks
- Calendar-style date, digital event time, and live countdown
- Existing personalized guest links retained, with a copy-link button
- Per-event custom CSS and sanitized decorative HTML
- Copyable AI design prompt, JSON importer, and isolated live preview
- SQLite database stored in a Docker volume
- Health check endpoint for reverse proxies
- Organizer notification inbox for RSVPs, polls, and potluck updates
- Optional organizer email notifications
- Guest opt-in email alerts for all event activity
- Guest activity feed with privacy-aware RSVP updates
- Organizer announcements and manual reminders
- Browser push notifications without requiring guest email or accounts
- Separate push categories for event changes, reminders, RSVPs, potluck, polls, and announcements
- RSVP-by deadline with late-response protection for unanswered guests
- Scheduled reminders with automatic push and optional email delivery
- Owner and co-host accounts with per-event access
- Owner-confirmed event deletion
- AI theme importer that accepts labeled/fenced CSS and HTML as well as legacy JSON

## Quick start

PartyForge runs on your own computer or server using Docker. This download is the app source, not a phone or Windows installer. Each installation starts with its own empty database.

You need Docker with Docker Compose (Docker Desktop on Windows or macOS, or Docker Engine with the Compose plugin on Linux).

1. [Download PartyForge as a ZIP](https://github.com/COBO5671/partyforge/archive/refs/heads/main.zip) and extract it. Open a terminal in the extracted folder containing `compose.yaml`.
2. Copy `.env.example` to `.env`.
   On Windows PowerShell: `Copy-Item .env.example .env`. On Linux/macOS: `cp .env.example .env`.
3. Open `.env` in a text editor and replace `SECRET_KEY` with a long random value and `ADMIN_PASSWORD` with a strong unique password. Set `ADMIN_NAME` to your display name. The example uses `admin` as `ADMIN_USERNAME`.
4. Run:

```bash
docker compose up -d --build
```

5. On the same computer, open `http://localhost:5050/admin/login` and log in as `admin` with the password you set. From another device on your network, use `http://YOUR-SERVER-IP:5050/admin/login`.

Keep Docker running while using the app. Guests on the internet need a publicly reachable HTTPS address for your installation; a localhost or home-network address only works locally. Set `PUBLIC_BASE_URL` to your public address and `SESSION_COOKIE_SECURE=true` when using HTTPS.

Your account is created on the first launch. After that, change its password from **Account**; editing `ADMIN_PASSWORD` does not reset an existing account.

For Cloudflare Tunnel, point the public hostname at `http://localhost:5050`.

Browser push requires HTTPS for normal domains. Guests enable it from their personalized invitation without creating an account or providing an email address. On iPhone/iPad, the guest must first add the invitation to the Home Screen, open that installed web app, and then tap **Enable browser notifications**.

## Updating

Download the latest ZIP and replace the application files in your existing folder, preserving your `.env`. If you installed with Git, run `git pull` instead. From that same folder:

```bash
docker compose build --pull
docker compose up -d
```

Your database and uploaded banners remain in the `partyforge_data` Docker volume.

PartyForge intentionally uses one threaded Gunicorn worker with SQLite. This prevents multiple startup workers from racing while the database creates its initial tables and is ample for a personal event site.

## Back up

```bash
docker compose stop
docker run --rm -v partyforge_partyforge_data:/data -v "$PWD":/backup alpine tar czf /backup/partyforge-backup.tgz /data
docker compose start
```

The actual volume name can vary with the folder name. Run `docker volume ls` if needed.

## AI decoration workflow

1. Create an event.
2. Open **Decorate**.
3. Describe the theme you want.
4. Copy the generated prompt into ChatGPT, Open WebUI, LM Studio, or another model.
5. Paste the model's complete response into PartyForge.
6. Select **Apply & save AI theme**. The importer accepts the labeled CSS/HTML sections generated by the prompt, Markdown fences, and the older JSON format.

AI output is decoration only. PartyForge strips scripts, iframes, forms, event handlers, inline styles, remote URLs in CSS, and other unsafe constructs. Custom JavaScript is deliberately unsupported.

## Included visual example

Open `examples/thanksgiving-rsvp-demo.html` directly in a browser to see a complete Thanksgiving/Friendsgiving RSVP concept. Its floating emojis react to mouse movement, touch, and taps. In the production app, that interaction should be provided by a trusted built-in motion engine while AI-generated themes supply the emoji set, colors, density, and styling.

## Environment variables

- `APP_NAME`: displayed organizer app name
- `SECRET_KEY`: random Flask session secret
- `ADMIN_PASSWORD`: organizer password
- `DATABASE_URL`: defaults to SQLite at `/data/partyforge.db`
- `SESSION_COOKIE_SECURE`: set to `true` once accessed only through HTTPS
- `PORT`: internal Gunicorn port; normally leave at 5050
- `PUBLIC_BASE_URL`: the public HTTPS address, such as `https://events.example.com`; used for links in scheduled emails
- `ADMIN_NAME`: first owner’s display name; defaults to `Cody`
- `ADMIN_USERNAME`: first owner’s login name; defaults to `cody`
- `ADMIN_EMAIL`: first owner’s email address
- `VAPID_SUBJECT`: contact URI used for browser push, normally `mailto:you@example.com`
- `REMINDER_POLL_SECONDS`: how often scheduled reminders are checked; defaults to 60 seconds

## Hosts and co-hosts

The owner can open **Hosts** from an event and create or add co-host accounts. Co-hosts can edit event details, manage guests and party extras, decorate, post announcements, schedule reminders, and view notifications. Only the event owner can change the host team or permanently delete the event. Every host can change their password from the account page.

## Browser notification behavior

- Guest subscriptions belong to the personalized guest link and do not require an email address.
- Host subscriptions belong to the signed-in host account and are configured from **Alerts**.
- Each browser chooses categories independently: event changes, reminders, RSVPs, potluck, polls, and announcements.
- Email remains optional and separate from browser push.
- PartyForge generates and retains its VAPID signing keys inside the Docker data volume. Keep that volume when updating or browser subscriptions will need to be enabled again.

### Email notifications (optional)

The organizer inbox works immediately without any email service. To also send email, add these values to `.env` and restart the container:

```dotenv
HOST_EMAIL=your-email@example.com
MAIL_FROM=your-email@example.com
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USERNAME=your-email@example.com
SMTP_PASSWORD=your-smtp-password
SMTP_USE_TLS=true
```

For Gmail, use `smtp.gmail.com`, port `587`, your Gmail address for the username/from fields, and a Google App Password—not your normal Google password. Google requires two-step verification before it will offer App Passwords.

Guests can enter or update their email on their private invitation and choose **Email me all updates**. Subscribed guests receive event changes, host announcements/reminders, public RSVP activity, poll activity, and potluck changes. RSVP notes and dietary information are never sent to the guest group. A guest can unsubscribe by clearing that checkbox and saving their RSVP again.

Email delivery is best-effort: if SMTP is unavailable, RSVP and potluck submissions are still saved and the in-app notifications remain available.

## Notes

This is an original self-hosted event app, not affiliated with Partiful. It intentionally starts with a single organizer password and no guest accounts. For internet exposure, use HTTPS and a strong password.

## September 2026 maintenance update

Static CSS and JavaScript URLs now include a content hash so browsers fetch changed assets after deployment. Browser notifications are visible on personal invitations before RSVP; open invitations explain the option before signup. Email updates are in a clearly optional expandable section. Guests must tap Enable and accept the browser permission prompt; notification permission cannot be enabled silently. Notification categories reload correctly and opting out of one invitation preserves other invitations on the same device. Deadlines and scheduled reminders now use the event timezone rather than the server timezone.

To deploy these fixes, replace the application source files on the server, keep the existing `.env` and data volume, and run `docker compose up -d --build`. No database migration is needed.
